# Imena — Architectural Interiors

A luxury architectural design atelier specializing in precision-engineered doors, hardware, kitchens, lighting, wardrobes, and complete interior systems.

## About

Imena is a design, supply and installation atelier founded in Milan in 1984. We craft architectural doors, hardware, kitchens, lighting, wardrobes, and complete interior systems for the world's most considered residences, hotels, and cultural institutions.

**Locations:** Milan · London · Dubai

## Built With

- [TanStack Start](https://tanstack.com/start) — React framework
- [TypeScript](https://www.typescriptlang.org/) — Type safety
- [Tailwind CSS v4](https://tailwindcss.com/) — Styling
- [shadcn/ui](https://ui.shadcn.com/) — Component library
- [React Router](https://reactrouter.com/) — Routing

## Design System

- **Palette:** Matte black, ivory, champagne gold
- **Typography:** Playfair Display (display), Inter (body), JetBrains Mono (monospace)
- **Animations:** Custom easing curves, Ken Burns effect, reveal transitions

## Development

```sh
# Install dependencies
npm i

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

```
src/
├── components/       # Reusable UI components
├── config/          # Business configuration
├── data/            # Product catalog and content
├── hooks/           # Custom React hooks
├── lib/             # Utility functions
├── routes/          # Page components (TanStack Start)
└── styles.css       # Global styles and design tokens
```

## Features

- **Product Catalog** — Filterable archive of architectural objects
- **Project Builder** — Curate specifications and request consolidated quotes
- **Wishlist** — Save favorite objects
- **Inspiration Gallery** — Curated interior compositions
- **Consultation Booking** — Private design consultations
- **Responsive Design** — Optimized for all screen sizes
